Supported now

DECLARE (INTEGER, REAL, STRING, CHAR, BOOLEAN), assignment ← or <-, INPUT, OUTPUT (one expression), IF / ELSE / ENDIF and WHILE / ENDWHILE. Arithmetic, comparisons, AND, OR, NOT and string concatenation & are supported. One statement per line; comments begin with //.

Arrays, FOR, REPEAT, CASE, subroutines, files and built-in functions are not yet supported. Input is supplied before running. Execution stops after 10,000 instructions.
